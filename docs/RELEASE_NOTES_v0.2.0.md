# 浮言 FloatLRC v0.2.0

**发布日期：2026-11-20**

锁屏显示、逐字填色重做，以及暂停冻结修复。

## 下载

- `FloatLRC-v0.2.0.apk`（约 8.0 MB）
- SHA-256：`2df14dbd608acc4f52fd1f870fee70d80006d5ae78b7b3393195f0ece9e8db8f`

## 亮点

- **锁屏显示**：开启后借助无障碍服务使用 `TYPE_ACCESSIBILITY_OVERLAY`，悬浮歌词显示在锁屏界面之上；主界面新增开关与无障碍状态入口。
- **逐字填色重做**：按字素簇建立时间轴，多字词片段按字数均分；用文字排版的真实字符包围盒裁剪，自动适配居中与自动换行。没有逐字数据时把整行时长按字均分，不再整行匀速从左到右扫过。
- **暂停冻结**：3.x 服务端没有播放状态时，通过 `AudioManager.isMusicActive()` 判断音乐输出是否活跃，暂停后冻结歌词进度，恢复播放后从原处继续。
- 悬浮窗运行中可在普通悬浮窗与无障碍悬浮窗之间切换，位置与设置保持一致。

## 安装与使用

1. Android 8.0（API 26）及以上。
2. 安装并激活 SuperLyric 系统服务（LSPosed）。
3. 授予悬浮窗权限与通知权限。
4. 锁屏显示：打开「锁屏显示」→ 在系统无障碍设置中启用「浮言锁屏歌词」。Android 13 若提示受限设置，需在应用信息中允许受限设置。

## 兼容性

- 3.x 服务端通常不提供逐字时间，此时按整行时长把每个字依次点亮，节奏为估算值。
- 4.0 服务端的逐字时间路径已实现，仍待更多实机验证。

## 已知问题

- 暂停检测基于系统音乐输出活动；暂停时若其他应用仍在输出音乐，可能判断不准。
- 暂不支持多行歌词滚动、通知栏播放控制、开机自启。
- MIUIX 仍处于实验阶段，后续升级可能需要适配 API 变化。
